# Projeto_EDB_II

# Árvores AVL e Rubro-Negra em C++

Projeto em C++ que implementa árvores AVL e Rubro-Negras para gerenciamento de encomendas por meio de IDs.

## Funcionalidades

- Inserção, remoção e busca de IDs.
- Percurso em ordem crescente.
- Exibição da estrutura das árvores.
- Estatísticas de altura e número de rotações.
- Menu interativo no terminal.

## Tecnologias

- C++17
- Bibliotecas padrão: `iostream`, `algorithm` e `string`

## Como compilar e executar

Compile com o `g++`:

```bash
g++ -std=c++17 main.cpp -o arvores
```

**Linux/macOS:**

```bash
./arvores
```

**Windows:**

```powershell
.\arvores.exe
```

## Objetivo

Estudar e comparar o funcionamento, o balanceamento e as operações de árvores binárias de busca AVL e Rubro-Negras.
